Repeat in a fresh workspace copy

Preserve the completed experiment. Copy the code and inputs into a separate directory with new output folders. Training refuses to overwrite an existing run. Use Python 3.10, requirements-windows.lock.txt, and the official code/model/data revisions recorded in data/provenance.json.

.\.venv\Scripts\python.exe apply_windows_fixes.py
.\.venv\Scripts\python.exe language_experiment\prepare_data.py
.\.venv\Scripts\python.exe train_qlora_4080.py --steps 300 --data datasets/language_experiment --output training_runs/qlora_language_3tasks
.\.venv\Scripts\python.exe language_experiment\finish_run.py
.\.venv\Scripts\python.exe improvement\train_augmented.py
.\.venv\Scripts\python.exe improvement\run_extension.py

Data preparation expects the verified RLDS shards under datasets/training_subset/raw. Evaluation uses five cells per subprocess to avoid the observed Windows MuJoCo asset-loading issue, resumes completed cells, and checks protocol/checkpoint hashes. A changed protocol requires a separate output location.

Training: seed 7, 300 updates, batch 1, accumulation 4, NF4, rank 8, alpha 16, query/value targets, learning rate 1e-4. Different hardware or dependency versions may change numerical outcomes.
