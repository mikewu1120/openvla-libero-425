1. Language Robustness in OpenVLA

Target: 25 seconds

My project asks whether a robot policy follows the same goal when we change only the wording of its instruction. I study OpenVLA on a twelve gigabyte laptop GPU. The contribution is a controlled local experiment, not a reproduction of the paper’s full benchmark. I compare the pretrained Spatial checkpoint, continuation training with original instructions, and an exploratory training intervention using separate paraphrases.

2. Equivalent instructions, different behavior

Target: 45 seconds

Both instructions describe the same object and the same destination. A semantic paraphrase should ideally preserve the ability to complete the task. However, the policy generates actions from both images and text. A small action difference changes the next image and can change the entire trajectory. Our experiment therefore measures closed-loop task success, rather than text similarity or a single predicted action. The objects and the initial robot state remain fixed across the paired conditions.

3. A controlled experiment on limited hardware

Target: 55 seconds

OpenVLA combines image features and a language model to produce tokenized robot actions. We start from the official checkpoint already fine-tuned on LIBERO-Spatial. To fit the laptop, the base uses four-bit NF4 weights. We freeze it and update only rank-eight adapters in the query and value projections. Each training run has three hundred optimizer updates and the same task-balanced data. The measured peak allocated training memory is about five point five one gibibytes. This is a deliberately small continuation experiment, with a different recipe from the full paper.

4. Paired evaluation design

Target: 50 seconds

The first study crosses three tasks, three instruction forms, two models, and ten initial states per task, giving one hundred eighty rollouts. Every paired condition starts from the same simulator state, which we verify exactly. A run succeeds only when the environment reports task completion within two hundred twenty actions. The primary robustness gap is original success minus the mean success of the two paraphrases. For uncertainty, we resample initial states within each task, keeping all paired conditions together. This preserves the dependence across instructions and models.

5. Original-only training improves some success rates

Target: 55 seconds

On thirty rollouts per condition, original-instruction success increases from seventy-three point three to eighty percent. Paraphrase one increases from fifty to sixty-three point three percent. Paraphrase two remains at sixty percent. But the original-minus-paraphrase gap is eighteen point three percentage points both before and after training. The confidence interval for its change ranges from minus fifteen to plus sixteen point seven points. This study therefore does not establish improvement in the primary robustness metric. Equal aggregate rates also do not imply identical behavior.

6. The average hides task-specific regressions

Target: 45 seconds

The first two tasks improve in total success, but the center-bowl task declines from nineteen to fifteen successes out of thirty. Across the ninety matched conditions, thirteen change from failure to success and seven change from success to failure. For paraphrase two alone there are six improvements and six regressions, leaving its average unchanged. This is why we need both aggregate statistics and paired videos. A smaller gap could also arise because original-instruction performance became worse, so the absolute success rates must remain visible.

8. Exploratory intervention: language augmentation

Target: 50 seconds

The observed sensitivity motivates a targeted intervention. Instead of changing the images or increasing training time, we cycle between the original instruction and two additional training paraphrases. These training sentences are different from the evaluation sentences. The model starts again from the same official checkpoint with the same seed, images, task balance and three hundred updates. We then evaluate another ninety rollouts on the existing cases. Because we designed this intervention after inspecting the initial results, it is exploratory and reuses the test set. It is not an independent confirmation.

9. Augmentation results

Target: 50 seconds

The augmented model succeeds in 86.7 percent of original instructions, 63.3 percent of paraphrase one, and 80.0 percent of paraphrase two. Its original-minus-paraphrase gap is 15.0 points. Compared with original-only training, the gap is smaller, with a change of -3.3 points and a paired interval from -13.3 to 6.7. The paired interval includes zero, so this follow-up does not establish a gap reduction. The intervention was designed after inspecting the initial results, and the same evaluation cases are reused. We must therefore interpret it as an exploratory result, not broad language generalization.

10. What this project establishes

Target: 40 seconds

This project establishes that a small, quantized OpenVLA continuation experiment can run on the available laptop, with reproducible paired trajectories and videos. It also shows that equivalent wording can change closed-loop outcomes. Improvements in offline loss or average task success do not by themselves establish language robustness. The next confirmatory study should fix the intervention first, use new paraphrases and initial states, repeat training across seeds, and include a same-scene different-target control. That final control tests whether the policy actually needs the language, rather than exploiting visual regularities.

The intervals condition on the three selected tasks and one training seed. Each bootstrap draw keeps all model and instruction outcomes for a sampled initial state together. This is not a broad confidence statement over unseen robot tasks. Questions to prepare for

What did you train?

Low-rank query/value adapters on a frozen NF4 OpenVLA LIBERO-Spatial checkpoint. Each run has 300 updates and 4.19 million trainable parameters. This is not training a 7B model from scratch.

What is the main result?

Original-only training increases total success but does not narrow the primary robustness gap. Augmentation reaches 69/90 successes, yet its gap-change interval [-13.3, 6.7] includes zero.

Does the interval prove no effect?

No. It is compatible with both a reduction and an increase of the gap on these fixed tasks. It does not establish equivalence.

Why are 270 rollouts not independent?

Each task-state case is reused across models and wordings. Bootstrap resampling keeps those conditions together and resamples states within each fixed task.

Is the gain caused by better language understanding?

The experiment does not isolate that mechanism. Different-target and no-instruction controls would help test language dependence.

Was the test set used during training?

Added training strings differ from evaluation paraphrases. However, augmentation was designed after inspecting original results and reuses evaluation cases, so it is exploratory. The base also already saw LIBERO-Spatial.

Why show selected videos?

They illustrate paired gains, regressions and disagreements. Selection is disclosed; the complete gallery and numerical results give frequencies.

How does this fit 12 GB?

Frozen four-bit weights, limited rank-eight adapters, batch size one and gradient checkpointing. Peak allocated memory is about 5.51 GiB, which is not total device usage.

What should be done next?

Freeze the recipe, use new paraphrases and initial states, repeat training seeds and add language-necessity controls. Do not repeatedly tune on this test set.
